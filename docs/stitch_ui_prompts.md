# Just Spark — Google Stitch Prompt Pack (MVP, light theme)

**How to use:** Google Stitch designs one screen per prompt. Do them **in order, one at a time**:

1. First paste **Prompt 0 (Design System)** to set the style.
2. Then paste **Prompt 1**, generate, save. Then **Prompt 2**, generate, save. And so on.
3. Every screen prompt already starts with a short style line, so each works standalone even if
   Stitch loses context between generations.
4. When you want the dark version, use the **Dark-mode pass** at the end.

Brand: **Just Spark** · warm, friendly, trustworthy dating app · **light theme** · mobile (iOS + Android).

---

## Prompt 0 — Design System (paste this first)

> You are designing a mobile dating app called **Just Spark**. Set up a reusable design system.
> Mood: warm, friendly, safe, premium — approachable, never sleazy. Mobile-first, iOS and Android.
> **Use a LIGHT theme.**
> Colors: primary spark coral #FF5864 (buttons and active states), soft pink surfaces #FBEAF0,
> white #FFFFFF and light grey #F7F7FA backgrounds, charcoal text #1A1A2E, muted text #6B6B7B,
> verified blue #3B9EFF, success green #2ECC71, hairline borders #ECECF2.
> Typography: clean geometric sans-serif (Inter / SF Pro), large friendly headings, high-contrast
> body. Shapes: large rounded corners (16–24px), pill-shaped full-width primary buttons, rounded
> profile photos, soft shadows, generous white space. Components to reuse everywhere: photo-first
> swipe cards, coral gradient/solid primary buttons, interest chips, bottom tab bar
> (Discover · Matches · Chat · Profile), floating like/pass buttons, toasts, empty-state
> illustrations, skeleton loaders, rounded line icons. Copy tone: encouraging, human, concise.

**Style line to reuse:** each prompt below starts with —
*"In the Just Spark style (light theme, coral #FF5864, soft pink surfaces, rounded, friendly):"*

## Dark-mode pass (after light theme is locked)

For each of these key screens, add: *"Now redesign this screen in DARK mode: backgrounds #14141C
and #1E1E28, text #F5F5F7, keep coral #FF5864 as the accent and verified blue vivid."*
Apply to: **Discover deck, Card Detail, Conversation List, Chat, My Profile, Settings.**

## Tips

- Generate the shared components first (buttons, cards, tab bar, chips) so later screens match.
- Ask for each state explicitly (empty, loading, error, filled).
- Export to Figma from Stitch and assemble the flows there.
